# gmenu-rrm-dush

Utility toolkit: menu runtime, disk-usage tool and force-delete helper.

- `gmenu.ps1` / `GMenuRuntime.ps1` / `profile-wrappers.ps1` - PowerShell menu runtime and wrappers
- `dush.py` / `dush_native.cpp` / `dush.exe` - disk usage analyzer (Python + native build)
- `ForceDeleteAnything.csproj` / `Program.cs` / `ForceDeleteAnything.exe` - unlock-and-delete utility
- `build-native.ps1` - builds the native dush binary
